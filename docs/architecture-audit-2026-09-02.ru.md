# Технический и архитектурный аудит — 2 сентября 2026

Аудит выполнен для исходного репозитория ManacostTeam/OpenBot: React/Vite-клиент, Hono API,
AG-UI/CopilotKit runtime, PostgreSQL/Drizzle, worker и публичный embed API. Production-трафик во
время аудита не изменялся.

## Итог

Критичная найденная проблема была в границе embed API: URL проверялся на конкретного сотрудника,
но после проверки runtime терял этот идентификатор и загружал весь roster владельца. Это создавало
лишнюю поверхность для handoff и увеличивало стоимость построения runtime. Проблема исправлена и
закреплена интеграционными тестами.

## Найденные проблемы и исправления

| Приоритет | Область | Что было | Что сделано |
| --- | --- | --- | --- |
| Высокий | Embed API / авторизация | Скоуп токена терялся между resolver и runtime; владелец мог получить полный список агентов через один embed-run. | Добавлен `agentId` в контекст актёра, SQL-фильтр active/tombstone roster и `onlyBotId` при построении runtime. Для scoped embed-run handoff/escalation не монтируются. |
| Средний | PostgreSQL / производительность | Поиск embed-токена по SHA-256 не имел индекса и деградировал в полный просмотр `agent_profiles`. | Добавлен уникальный B-tree индекс `agent_profiles_embed_token_hash_idx` и миграция `0035_parallel_tenebrous.sql`. |
| Низкий (долг) | Структура | `server/src/index.ts`, `server/src/app.ts` и несколько хранилищ крупные; границы уже выделены фабриками, но дальнейшее разделение снизит стоимость изменений. | В текущем аудите не выполнялось рискованное массовое дробление. Следующий шаг — выделять вертикальные модули по контрактам с characterization-тестами. |

## Отдельно отслеживаемый baseline

`bun run format:check` по-прежнему сообщает пять старых расхождений форматтера в sign/Telegram/health
и nginx-тестах. Они не относятся к аудиту и намеренно не смешивались с функциональным изменением.
Штатный `/home/debian/server/tools/ai-quality/bin/ai-check` в этом репозитории некорректно вызывает
`npm exec tsc` и завершается справкой TypeScript; поэтому typecheck, lint, тесты, сборка и security
были запущены проектными командами напрямую.

## Контракт для embed-интеграции

После миграции токен по-прежнему передаётся только через `x-manacost-embed-token` или Bearer. Он
действует только на URL выданного сотрудника; runtime видит только этого сотрудника и не получает
инструменты перехода к другим агентам. Перед production rollout нужно применить миграцию 0035 и
проверить smoke-запрос `POST /api/copilotkit/agent/{agentId}/run` с токеном в разрешённом Origin.
