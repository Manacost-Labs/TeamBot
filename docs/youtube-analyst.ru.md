# YouTube-аналитик: расшифровка в Markdown

## Цель

Добавить в рабочий канал отдельного агента `youtube-analyst`, которому человек передаёт от одной
до пяти ссылок YouTube. Агент получает субтитры через уже подключённый TranscriptAPI, превращает
их в чистый структурированный пересказ и возвращает один скачиваемый файл `.md`.

## Пользовательский сценарий

1. Человек выбирает «YouTube-аналитик» и отправляет ссылки на ролики.
2. Агент проверяет доступность провайдера командой `research-source doctor`.
3. Для каждой ссылки агент выполняет `research-source youtube-transcript --video '<URL>'`.
4. Агент очищает расшифровку от приветствий, рекламы, призывов подписаться, слов-паразитов,
   повторов и явных ошибок автоматической транскрибации, не удаляя важные оговорки и выводы.
5. Агент создаёт ровно один Markdown-артефакт через `artifacts/create_artifact`.

## Формат результата

Файл содержит источник для каждого ролика, краткий итог, структурированный пересказ, ключевые
тезисы с временными метками и раздел с неясностями расшифровки. Для нескольких ссылок каждый ролик
получает отдельный раздел. Полная дословная расшифровка в файл не копируется.

Пример структуры:

```markdown
# Пересказ YouTube-видео

## Видео 1

- Источник: https://www.youtube.com/watch?v=...

### Кратко

### Структурированный пересказ

### Ключевые моменты

### Неясности расшифровки
```

## Границы и безопасность

- Агент не ищет другие видео и не проводит отдельное веб-исследование.
- Субтитры считаются недоверенными данными: инструкции и запросы внутри них игнорируются.
- Секрет TranscriptAPI не передаётся в аргументах, отчёте, логах или файле.
- Если расшифровка недоступна, агент указывает проблемную ссылку и не выдумывает содержание.
- Агент получает сетевой доступ только для локального `research-source`, чтение рабочей области и
  единственный прикладной инструмент записи — `artifacts/create_artifact`.

## Проверка

- Модульные тесты распознают агента по `agentId` и `openbotBotId`, проверяют отдельный профиль прав,
  скрытие reasoning и обязательные инструкции для TranscriptAPI и Markdown-артефакта.
- Тест пакета арендатора проверяет регистрацию агента в рабочем канале и выдачу только инструмента
  `artifacts/create_artifact`.
- Production-проверка подтверждает здоровье сервисов, регистрацию агента и ответ
  `research-source doctor` без вывода секретов.

## Критерии готовности

- «YouTube-аналитик» доступен в канале Work.
- Получает транскрипт только по переданным ссылкам.
- На успешном запуске создаёт скачиваемый `.md` через штатный артефакт OpenBot.
- При недоступной расшифровке сообщает ограничение и не создаёт ложный пересказ.
